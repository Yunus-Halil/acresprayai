# Virginia, in plain language

This is SwathWise's first sourced state research catalog. It gathers Virginia Tech's 739 Weed ID entries, compares their scientific names against the USDA Virginia state plants checklist, notes named weeds in the 2026 field-crop guide, and separately records Virginia's 26 regulated noxious-weed listings. Sixteen law listings were not an exact name match to the Virginia Tech index and are preserved as separate records until someone resolves possible alternative scientific names.

The result is 755 source records, **not 755 verified farm weeds**. The Virginia Tech clinic index includes plants outside farm fields. The easy-to-sort table shows which entries have direct crop or pasture guide support, which are only in a broad identification index, and which are listed in law. Some names need taxonomic review. Profile habitat keywords help prioritize that work but do not certify crop relevance.

For a farmer-facing release, a weed expert still needs to check the source records and approve a farm subset. To identify weeds from drone imagery, SwathWise also needs separately collected and tested images. This package makes that work organized and traceable; it does not claim every Virginia weed, farm occurrence, field-level abundance, or automated recognition.
