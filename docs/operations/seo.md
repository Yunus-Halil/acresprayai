# SEO and link previews

Everything that decides how swathwise.com appears in a search result or a pasted link.

## Where the tags live, and why there are two places

| | Reaches | Set in |
|---|---|---|
| Static head | **Every** crawler, including ones that do not run JavaScript | [`index.html`](../../index.html) |
| Per-route head | Only crawlers that render JS — in practice Googlebot | [`src/components/Seo.tsx`](../../src/components/Seo.tsx) |

This split matters and is not a temporary state to be tidied away.

The crawlers behind LinkedIn, Slack, iMessage, WhatsApp and Discord previews fetch the served
HTML and stop. They never run the React app. So **whatever is in `index.html` is what every
shared link previews as**, regardless of which route the link points at. `Seo.tsx` fixes the tab
title, the description and `noindex` per route, and Googlebot does honour it — but a link to
`/apply` still previews with the homepage's card.

That is an acceptable trade today: the only links anyone shares are `/` and `/apply`, and both
sell the same thing. Making per-route previews real needs pre-rendering, which is a build change,
not a metadata change.

## The homepage tags

| Tag | Value |
|---|---|
| `<title>` | SwathWise — Precision spray missions from drone imagery *(55 chars)* |
| `description` | Upload drone images, get a stitched map of your farm, and let AI find the crops that need spraying — with flight plans ready for your drone. *(140 chars)* |
| `canonical` / `og:url` | `https://swathwise.com/` |
| `og:image` / `twitter:image` | `https://swathwise.com/share-card.png` (1200×630) |
| `twitter:card` | `summary_large_image` |

Kept under 60 and 155 characters respectively so neither is truncated in a result.

The description is the landing page's own hero sub-heading, not marketing written for the meta
tag. If the hero copy changes, change this too — a description that no longer matches the page
is worse than a generic one.

## The share card

`public/share-card.png`, generated by `npm run build:share-card`
([`scripts/build-share-card.cjs`](../../scripts/build-share-card.cjs)).

Built from the site's own palette and mark rather than cropped from a screenshot, and
**deliberately carries no text**. Text baked into a share card is the thing that quietly starts
contradicting the page — a headline or a claim that changed six months ago and nobody re-exported
the image. `og:title` and `og:description` supply the words on every surface that renders a
preview, and those live next to the page.

Regenerate it after changing the logo. It is committed, not built in CI, because link-preview
crawlers need it at a stable URL whether or not a build has run.

## Indexability

| Route | Indexed | How |
|---|---|---|
| `/` | yes | In the sitemap |
| `/apply` | yes | In the sitemap |
| `/auth` | no | `noindex` + `Disallow` |
| `/app/*` | no | `noindex` via `AppLayout` + `Disallow` |
| `/admin/*` | no | `noindex` + `Disallow` |

Both belt and braces, and the belt is load-bearing. The Vercel SPA rewrite means `/app/fields`
returns **200 with the app shell**, not a 404 — so a crawler that found the URL anywhere would
otherwise index an empty page under the homepage's title. `robots.txt` stops the fetch;
`noindex` catches anything that fetched anyway.

`Seo.tsx` removes the robots tag again when moving to a public route, so navigating
`/app` → `/` in a single session cannot leave the landing page carrying `noindex`.

## Files

- [`public/robots.txt`](../../public/robots.txt) — allows all, disallows the signed-in surfaces, points at the sitemap
- [`public/sitemap.xml`](../../public/sitemap.xml) — the two public routes. **Hand-maintained**; add a public route, add it here
- Structured data — a single `Organization` JSON-LD block in `index.html`: name, url, logo, description. Nothing we cannot stand behind; no ratings, no invented `sameAs` profiles

## Verifying a deploy

```bash
curl -s https://swathwise.com/ | grep -E '<title>|og:image|canonical'
curl -s https://swathwise.com/robots.txt
curl -s https://swathwise.com/sitemap.xml
curl -sI https://swathwise.com/share-card.png | head -3   # expect 200 image/png
```

Then paste the URL into <https://www.opengraph.xyz> or a Slack message to yourself. A preview
crawler caches aggressively — LinkedIn's Post Inspector has a "scrape again" button, and it is
usually needed after changing a tag.
