# Corn research (2026-10-23)

The narratives behind `crop-profiles/corn/`. Each report ends with a parameter table (value or range, units, geography,
source, evidence strength) and a list of gaps. Figures seen only in a search snippet are marked "(snippet)", and our
own arithmetic is labelled.
